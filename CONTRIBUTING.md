# Contributing to CampusCore

Thank you for improving CampusCore.

## Development workflow

1. Read `docs/setup.md` and `docs/architecture.md`.
2. Create a focused branch from `main`.
3. Keep domain rules independent of HTTP, EF Core, and React.
4. Add or update tests for behavior changes and regressions.
5. Run the checks in `docs/testing.md`.
6. Do not commit secrets, real student data, production exports, or private endpoints.
7. Open a pull request using the repository template.

Use Conventional Commits where practical. Security vulnerabilities must be reported through `SECURITY.md`, not a public issue.
