# Roadmap

## 0.1 — Foundation
- Modular architecture, authentication, PostgreSQL schema, core student lifecycle, CI, documentation.

## 0.2 — Academic operations
- Attendance, leave, marks, grading, timetable, announcements, reporting, imports/exports.

## 0.3 — Product hardening
- PWA resilience, richer accessibility automation, performance budgets, backup/restore operations, administrator workflows.

## 0.4 — Android and browser companion
- Reproducible Capacitor Android packaging from the shared React client.
- Native safe-area/runtime behavior, explicit API targeting, and Android CORS contract.
- Android debug-APK CI verification without committing generated Gradle output.
- Minimal-permission Manifest V3 CampusCore Companion preparation with validation and packaging CI.

## 1.0 — Production release
- Clean-install verification, migration upgrade testing, full E2E suite, deployment guide, signed Android release configuration, release artifacts, screenshots, final security/accessibility audit.
- Browser companion store-readiness review, icons/branding assets, and store policy/privacy metadata before publication.

See `what_changed.md` for the exact next executable tasks and verification state.
